# 플레이말로우 맞춤 평가·추천 기획

## 1. 검토 결론

첫 실행에 기준선 평가를 넣는 방향이 적절하다. 다만 사용자를 진단하거나 능력을 단정하는 검사가 아니라, 현재 플레이 상태를 파악해 오늘의 루틴을 고르는 짧은 온보딩으로 정의한다.

유사 서비스의 공통점은 다음과 같다.

| 서비스 | 첫 실행/개인화 방식 | 플레이말로우 적용점 |
| --- | --- | --- |
| Lumosity | 3개 게임으로 Fit Test를 진행해 기준선을 만들고, 결과를 첫 이용자 집단과 비교한 뒤 개인화 훈련에 사용 | 4개 핵심 능력을 짧은 미니게임으로 측정하고 비교 대신 내 기준선으로 안내 |
| Elevate | 과거 성과와 게임별 순위를 바탕으로 매일 필요한 기술을 우선하는 개인화 운동과 적응형 난이도 제공 | 실제 기록을 기준선과 합쳐 약한 영역을 우선 추천하고 반복 플레이로 갱신 |
| CogniFit | 훈련 전 기준선 평가, 진행 중 지속 측정, 능력별 난이도·과제 자동 조정. 훈련과 자유 플레이를 분리 | 평가 점수와 자유 플레이 기록을 분리 저장하고, 추천 근거를 사용자에게 설명 |

## 2. 첫 실행 흐름

1. **환영**: “2분 기준선 체크”라고 안내하고 의료 진단이 아님을 표시한다.
2. **튜토리얼**: 각 과제마다 한 문장 설명과 즉시 조작 가능한 큰 터치 영역을 제공한다.
3. **4개 미니 평가**: 기억 → 집중 → 계산 → 협응 순서로 각 15~25초 진행한다.
4. **결과**: 능력별 점수는 현재 플레이 기준선으로 표현하고, 강점·다음 연습 영역을 함께 보여준다.
5. **맞춤 루틴**: 가장 필요한 3개 게임을 추천한다. 추천 카드에는 “왜 추천하는지”를 한 줄로 표시한다.
6. **재평가**: 설정에서 언제든 다시 할 수 있다. 건너뛴 사용자는 균형 루틴으로 시작하고 홈에서 평가를 다시 안내한다.

### 평가 항목

| 능력 | 미니 과제 | 측정값 |
| --- | --- | --- |
| 기억 | 짧은 기호 순서를 보고 같은 순서로 선택 | 정답률, 오답 수 |
| 집중 | 파란 신호가 나타날 때만 탭 | 평균 반응시간, 성급한 탭 |
| 계산 | 목표 합을 만드는 숫자 선택 | 정답률, 선택 횟수 |
| 협응 | 순서대로 빛나는 점을 탭 | 완료율, 오답 수, 소요시간 |

평가 결과는 `0~100` 점수로 정규화한다. 결과 문구는 “기억력이 낮다”가 아니라 “오늘은 기억 루틴을 가볍게 시작해볼까요?”처럼 행동 중심으로 쓴다.

## 3. 추천 규칙

추천 점수는 다음 요소를 합친다.

```text
우선순위 = 약한 영역(55%) + 미플레이 보정(25%) + 최근 미실행 보정(20%)
```

- 초기 기준선은 `profile.skillScores`에 저장한다.
- 게임을 완료하면 점수를 능력별 `0~100`으로 변환해 기준선과 65:35로 이동 평균한다.
- 약한 영역을 우선하되 동일 게임이 1위부터 3위까지 독점하지 않도록 게임별 1개만 선택한다.
- 최소 1개는 새로운 게임 또는 최근 덜 한 게임을 섞어 탐색성을 유지한다.
- 카드에 `약한 영역 보완`, `아직 플레이하지 않음`, `최근 결과 반영` 중 하나를 표시한다.
- 평가를 건너뛴 경우 모든 능력을 50점으로 시작해 기본 순환 추천을 제공한다.

## 5. 그래픽·모션 품질 기준

- 슬라임 마스코트는 idle 호흡 모션과 화면 진입 시 scale-in을 사용한다.
- 배경에는 저대비 유기적 빛과 미세한 부유 입자를 사용하되 텍스트 대비를 침해하지 않는다.
- 평가 미니게임은 신호·선택·성공 피드백에 150~260ms의 easing 모션을 사용한다.
- 버튼은 터치 즉시 축소-복귀, 성공 시 색·광택·햅틱·사운드를 함께 사용한다.
- 시스템 `reduced motion`을 존중하고, 실패 시 흔들림 대신 색과 문구로 안내한다.

## 6. QA 게이트

- 신규 설치: 평가 인트로 → 4개 과제 → 결과 → 맞춤 루틴 순서가 끊기지 않는다.
- 평가 중 앱 재실행/화면 전환 시 부분 결과를 추천 데이터로 저장하지 않는다.
- 건너뛰기: 기본 균형 추천으로 진입하고 재평가 경로가 남는다.
- 평가 결과가 0점·100점·동점이어도 추천 카드가 3개 생성된다.
- 게임 1회 완료 후 해당 능력 점수와 추천 순서가 실제로 갱신된다.
- 기존 저장 파일은 평가 필드가 없어도 기본값으로 안전하게 병합된다.
- Android 세로 화면 390×844 및 에뮬레이터 1080×2400에서 터치 영역·문구·모션을 확인한다.
- 본 기능은 의료 진단·치료·인지 저하 판정을 제공하지 않는다는 문구를 유지한다.
