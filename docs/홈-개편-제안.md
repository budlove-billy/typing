# 홈 화면 개편 제안 (2026-09-28)

시안: `generated_images/home-mock.html` (그림·숫자는 예시, 기능 없음)

## 지금 홈의 문제
- 흰 카드 + 이모지 아이콘 + 글 상자가 많아 '앱 설정 화면'처럼 보인다. 게임마다 새로 그린 세계 그림 36장이 홈에는 하나도 안 나온다.
- 할 일이 여러 개로 흩어져 있다: 오늘의 추천, 전체 게임 보기, 주간 챌린지, 오늘의 목표, 메달 컬렉션. 무엇부터 할지 한눈에 안 들어온다.
- 운세는 화면 한참 아래 칩 6개로만 있다. 눌러 보기 전에는 무엇이 나오는지 알 수 없다.
- 첫 화면의 절반이 소개·능력 영역 글이다(검색용). 사람에게는 스크롤만 길다.

## 참고한 방식
- **NYT Games**: 여러 데일리 퍼즐을 한 홈에 모으고, 퍼즐마다 '오늘 했음/안 했음'과 자정 카운트다운을 보여 준다. 매일 돌아오게 만드는 핵심.
- **Lumosity·Elevate**: '오늘의 운동 3개'를 하나의 묶음으로 주고 진행 링으로 채우게 한다.
- **Poki·CrazyGames**: 게임을 그림 표지로 가로 선반에 진열한다. 글이 아니라 그림으로 고르게 한다.

## 제안 구조 (위에서부터)
1. **오늘의 두뇌 3판** — 매일 바뀌는 3게임을 큰 그림 카드로. 진행 링 1/3, '다음 판 시작' 버튼 하나. **3판을 다 하면 '오늘의 행운 카드'가 열린다** → 게임과 운세를 하나의 보상으로 연결.
2. **오늘의 퍼즐** — 모아모아·크라운·탱고. 풀었으면 ✓와 걸린 시간, 안 풀었으면 NEW. 자정까지 카운트다운.
3. **오늘의 운세 미리보기** — 오늘의 한 줄·행운의 색·숫자를 바로 보여 주고(호기심), 오늘 운세·별자리·띠·타로로 이어지게.
4. **게임 선반** — 인기 게임, 능력별(칩으로 전환) 가로 스크롤. 표지는 게임 세계 그림.
5. **이번 주 나** — 주간 챌린지·메달을 두 칸으로 짧게.
6. **소개·FAQ** — 지금 글 그대로 맨 아래(검색용 글은 지우지 않는다).
- 아래 탭에 **운세** 칸을 추가: 홈 · 게임 · 운세 · 내 기록.
- 연속 방문 🔥 일수를 맨 위에.

## 기대 효과
- 첫 화면에서 할 일 하나(다음 판 시작)가 분명해진다.
- '3판 → 행운 카드', '데일리 퍼즐 ✓', '연속 🔥'가 매일 다시 올 이유가 된다.
- 운세가 게임의 보상이 되어 게임 → 운세 → 다른 운세로 머무는 시간이 늘어난다.

## 정할 것 (사용자)
1. 방향 승인 — 어두운 '게임 로비' 톤으로 갈지, 지금처럼 밝은 톤에 그림 표지만 넣을지.
2. '3판 → 행운 카드' 보상 연결 여부.
3. 아래 탭에 운세 추가 여부.

## 구현 메모
- 홈 CLS 수정(SEO 진단 1순위)을 개편에 같이 넣는다 — 새 칸은 모두 높이를 미리 잡는다.
- 게임 표지는 지금 세계 그림(가운데가 비어 있음)보다, 그 위에 게임의 대표 물건(왕관·해달·낱말패 등)을 얹은 표지를 따로 만드는 편이 낫다.
