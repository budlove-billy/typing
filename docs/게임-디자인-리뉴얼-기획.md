# 게임 디자인 리뉴얼 기획 (2026-09-27)

> 상태: 33종 모두 적용 완료(2026-09-27). 구현 = `tools/stage-skin/build.py` → index.html의 STAGE-SKIN 블록.

말로우 런을 먼저 바꾼 뒤(황혼 숲 횡스크롤), 나머지 **스킬 게임 33종**을 같은 방향으로 바꾼다.
문제: 모든 게임이 같은 파스텔 카드 + 흰 통계 박스 + 분홍 타이머라서 "앱 화면"처럼 보이고, 배경 그림은 흰색으로 88% 덮여 거의 안 보였다.

컨셉 보드·게임별 아트 원본: 무한 캔버스(`canvas/`) — 디자인 시스템 보드 1장 + 게임 월드 33장.

## 1. 원칙

1. **게임마다 하나의 "세계"** — 게임 내용과 맞는 장소를 그린 세로형 배경(가장자리에만 디테일, 가운데는 비워 둠). 흰 막을 걷고 그대로 보여 준다.
2. **공통 게임 UI 부품** — 어느 게임이든 같은 문법: 금속 명판 HUD(점수·목숨·레벨), 금테 캡슐 타이머(마지막 순간 빨간 빛), 안내문 알약, 입체 버튼, 반투명 어두운 '나가기'.
3. **읽어야 하는 것은 밝은 유리 패널 위에** — 글자·숫자·색 판단이 필요한 판(스트룹 단어, 스도쿠, 2048, 질문)은 흰 유리 패널에 올린다. 8/22에 맞춘 색 대비(스트룹 6색은 #eef1f7 기준)를 깨지 않기 위해서다.
4. **세계를 무대로 쓸 수 있는 판은 투명하게** — 받기(하늘), 두더지(들판), 카드짝(펠트 테이블), 버블(바닷속), 순서 잇기(별자리)처럼 배경 자체가 놀이판이 되는 게임은 판을 비우고 조각만 세계 위에 둔다.
5. **로직·점수·판정은 손대지 않는다** — CSS와 배경 이미지만 바꾼다(게임별 소폭 표시 보정 제외).
6. **시작·결과 화면도 게임답게** — 시작: 세계 그림 배너 + 로고형 제목 + 입체 난이도 칩·시작 버튼. 결과: 배너 위로 튀어나온 메달형 이모지 배지 + 큰 금색 점수.

## 2. 순서 (4 웨이브)

"게임답지 않음"이 가장 크게 느껴지는 순서 = 손으로 조작하는 아케이드 → 기억·소리 → 보고 고르는 게임 → 풀이형.
검색 유입이 있는 2048(말랑 2048)·스트룹(색깔 맞추기)은 각 웨이브 안에서 먼저 확인한다.

| 웨이브 | 게임 | 이유 |
|---|---|---|
| 1 아케이드 | 말로우 팡팡, 마시멜로 받기, 말로우 타워, 반응 속도, 순서 잇기, 버블 톡톡, 블록 채우기, 말랑 2048 | 조작감이 중요한데 가장 밋밋함 |
| 2 기억·청각 | 순간기억, 인원수 세기, 엔백, 카드 짝, 거꾸로 기억, 멜로디 기억, 리듬 따라하기, 높은음 찾기 | 제시→기억→응답 연출이 무대가 필요 |
| 3 주의·시각·공간 | 색깔 맞추기, 규칙 바꾸기, 화살표 집중, 다른 색 찾기, 다른 모양 찾기, 틀린 그림 찾기, 도형 회전, 슬라이딩 퍼즐 | 판 가독성 유지가 관건 |
| 4 계산·논리·언어 | 암산 게임, 어림 계산, 스도쿠, 컬러 소트, 픽셀 로직, IQ 테스트, 글자 맞추기, 숨은 단어 찾기, 길 따라가기 | 풀이 집중형 — 차분한 세계 |
