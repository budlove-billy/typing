## 1. 지금 소리가 단조로운 이유 (코드 점검 결과)

| 항목 | 지금 | 결과 |
|---|---|---|
| 음원 | 사인·삼각파 오실레이터 1~2개를 스피커에 바로 연결(`_tone`, `_beep`), 음량 0.05~0.16 | 모든 소리가 '삑' 계열. 저음·타격·공간감이 없다 |
| 믹싱 | 마스터 버스·컴프레서·리버브 없음 | 소리가 얇고 겹치면 뭉개지거나 작게 들린다 |
| 게임별 개성 | 약 30개 게임이 똑같이 `good`(740→988Hz 두 음)·`bad`(저음 글라이드) 두 개만 쓴다 | 어떤 게임을 해도 같은 소리 |
| 진행감 | 1콤보와 10콤보가 같은 소리. 음높이 고정 | 연속 성공의 쾌감·긴장이 쌓이지 않는다 |
| 긴장 | 60초 게임의 마지막 5초에만 짧은 틱 | 시간 압박이 소리로 전달되지 않는다 |
| 배경음악 | **없음** | 판 전체의 템포·분위기를 끌고 갈 장치가 없다 |
| 만들어 두고 안 쓰는 소리 | `combo`(0회), `count`·`go` 카운트다운(0회), `level`(1회), `record`(1회) | |
| 조용한 게임 | 스도쿠·IQ(버튼 탭만), 픽셀 로직(클리어 1개), 길 따라가기·타워(1~2개) | |
| 음량 설정 | 켜기/끄기만 | 음악·효과음 따로 조절 불가 |

게임별 호출 현황(sfx 종류):

- **good/bad만:** 순간기억, 인원수, 화살표, 어림, 글자 맞추기, 높은음, 반응, 멜로디, 리듬, 받기, 다른 색·모양
- **good/bad + 마지막 5초 틱:** 색깔 맞추기, 규칙 바꾸기, 엔백, 도형 회전, 순서 잇기, 버블, 암산, 팡팡
- **조금 더 있음:** 카드(flip), 2048(whoosh·win), 블록(level·콤보 배지), 거꾸로 기억(숫자 음), 말로우 런(점프·신기록 전용음)

## 2. 개선 방향 — 네 층

### ① 오디오 엔진 v2 (전 게임 공통, 파일 없이 합성 유지)
- **마스터 체인:** 효과음 버스 + 음악 버스 → 짧은 리버브(공간감) → 컴프레서·리미터(크게 들리되 찢어지지 않게).
- **음색 프리셋:**
  - 플럭(마림바·하프 느낌), 벨, 킥(저음 타격), 스네어·노이즈 히트, 코인
  - 서브 드롭(강한 실패), 라이저(긴장 상승), 우쉬(이동), 유리 깨짐(콤보 끊김)
- **자연스러움:** 같은 소리를 반복해도 음높이·음량이 ±3% 흔들려 기계적인 반복감을 줄인다. 동시 발음 수에도 상한을 둔다.
- **파일은 쓰지 않는다:** 오프라인 PWA 용량·캐시 부담이 없다. 배경음악도 합성 루프로 만든다.
  - 음원 파일로 가고 싶으면 AI 음악 생성(유료 크레딧)으로 판당 30초 루프 4종을 만드는 선택지도 있다.

### ② 공통 피드백 문법 (34게임에 한 번에 적용)

| 순간 | 제안 소리 | 노리는 감정 |
|---|---|---|
| 정답 | 펜타토닉 **계단** — 콤보가 오를수록 한 음씩 올라가고, 5·10콤보에 짧은 팡파르 | 연속 성공의 쾌감 누적 |
| 오답 | 둔탁한 저음 쿵 + 살짝 어긋난 버즈 | 확실한 '아차' |
| 콤보 끊김(5 이상에서) | 유리 깨짐 + 하강음 | 잃은 것의 아쉬움 → 다시 하고 싶게 |
| 시작 | 3·2·1·GO 카운트다운(이미 만들어 둔 소리 연결) | 판 시작의 긴장 |
| 마지막 10초 | **심장박동 킥**이 점점 빨라지고, 5초부터 틱 음높이가 오른다. 배경음악 템포·밝기도 올라간다 | 스릴·압박 |
| 어려움 문항 제한시간 | 남은 30%에서 빠른 틱 | 순간 판단 압박 |
| 타임업·게임오버 | 하강 스윕 + 징 | 끝의 무게 |
| 신기록 | 풀 팡파르 + 반짝임 | 최고의 보상 |
| 메달 획득 | 🥉→💎 등급마다 다른 짧은 멜로디(💎가 가장 화려하게) | 수집 동기 |

### ③ 적응형 배경음악 (4가지 분위기 × 강도 3단계)

| 분위기 | 대상 | 강도가 오르는 조건 |
|---|---|---|
| 아케이드 드라이브(킥·베이스·아르페지오) | 런·타워·팡팡·받기·반응·블록 | 속도·배속, 콤보 |
| 포커스 펄스(저음 맥박 + 신스 패드) | 60초 학습형: 색깔·화살표·규칙·회전·어림·암산·버블·순서·다른 색/모양·틀린 그림·엔백·단어 | 남은 시간(마지막 15초 급상승), 콤보 |
| 메모리 앰비언트(잔잔한 패드) | 순간기억·인원수·카드·거꾸로 | 레벨 |
| 퍼즐 칠(느린 로파이) | 스도쿠·픽셀·소트·슬라이드·2048·IQ·길 따라가기 | 거의 변화 없음(집중 방해 금지) |

- 학습형 게임도 '포커스 펄스'가 마지막 15초에 몰아쳐, 일반 게임처럼 긴장이 오르게 한다.
- **소리가 문제인 게임은 예외:** 멜로디·리듬·높은음·거꾸로 기억은 들려줄 때 음악을 끄거나 크게 줄인다. 높은음 찾기의 시험음은 지금처럼 순수한 사인파로 둔다(음색이 섞이면 판정이 흐려진다).

### ④ 게임별 시그니처 소리

| 게임 | 시그니처 |
|---|---|
| 말로우 런 | 발걸음 틱(속도에 맞춰 빨라짐), 점프 스프링+우쉬, 착지 쿵, 아슬아슬 통과 '휙', 충돌 임팩트, 100m마다 차임, 배속 상승 라이저 |
| 말로우 타워 | 깨무는 '아삭'(노이즈+저음), 포크 위험 '챙', 게이지 30% 이하 심장박동 |
| 말로우 팡팡 | 튀어나올 때 '뽀잉', 맞히면 뿅망치(콤보 음계), 폭탄 폭발 |
| 마시멜로 받기 | 받을 때 '퐁'(콤보 음계), 포크 '쨍' |
| 반응 속도 | 기다리는 동안 올라가는 긴장음, GO '딱', 빠를수록 높은 차임, 노고 실패 부저 |
| 순서 잇기 | 번호를 누를 때마다 음계가 한 칸씩 올라감(1→n 아르페지오), 판 완료 스윕 |
| 버블 톡톡 | 방울 터지는 소리(숫자 클수록 낮게), 목표 달성 물보라 |
| 블록 채우기 | 블록 '툭', 줄 삭제 스윕, 여러 줄은 화음, 시간 부족 경보 |
| 말랑 2048 | 밀기 스웁, 합치기 '말랑' 팝(타일 클수록 높게), 2048 팡파르 |
| 순간기억 | 숫자가 보일 때 반짝, 맞게 누르면 음계 상승, 라운드 클리어 |
| 카드 짝 | 뒤집기 '착', 짝 맞춤 차임(연속일수록 높게), 틀리면 되돌아가는 소리 |
| 엔백 | 글자마다 똑같은 중립 블립(글자를 소리로 알려주지 않음), 적중·오경보 |
| 다른 색·모양·틀린 그림 | 찾으면 반짝 차임, 틀리면 쿵, 레벨업 |
| 색깔·화살표·규칙·회전·어림·암산 | 공통 문법 + 포커스 펄스 음악 + 제한시간 틱 |
| 스도쿠 | 숫자 입력 '톡', 행·열·박스 완성 차임, 실수 버즈, 완성 팡파르 |
| 픽셀 로직 | 칸 칠하기 붓 소리, X 표시 '틱', 줄 조건 충족 차임 |
| 컬러 소트 | 붓기 '졸졸', 한 병 완성 코르크 '뽁' |
| 슬라이딩 | 타일 '딸깍', 제자리 맞춤 음 |
| 숨은 단어·글자 맞추기 | 글자 선택마다 음이 한 칸씩 올라감, 단어 완성 화음 |
| 길 따라가기 | 진행할수록 음높이가 오르는 지속음, 이탈 '긁힘', 완주 팡파르 |
| 인원수 세기 | 사람마다 소리를 내면 귀로 셀 수 있어 과제가 바뀐다 → 장면 전체에 은은한 발소리 앰비언트만 |
| IQ 테스트 | 선택 '톡', 페이지 넘김, 마지막 1분 틱 |
| 멜로디·리듬·높은음·거꾸로 | 시험음은 그대로. 정오답·라운드 전환만 공통 문법으로 |

## 3. 데모 측정 (오프라인 렌더링)

| 소리 | 최대(dBFS) | 평균 세기(RMS) |
|---|---|---|
| 지금 정답 → 제안 정답(1콤보) | −16.1 → −15.5 | −40.6 → −37.5 |
| 제안 10콤보 | −8.0 | −29.4 |
| 지금 오답 → 제안 오답 | −18.1 → −14.8 | −39.7 → −35.2 |
| 지금 신기록 → 제안 신기록 | −15.0 → −4.9 | −36.0 → −23.8 |
| 제안 💎 메달 / 런 충돌 / 타임업 | −6.3 / −6.8 / −3.1 | −22.4 / −25.2 / −21.6 |

- 평소 피드백은 지금과 비슷한 크기로 두고, 큰 순간(연속 콤보·신기록·메달·충돌·타임업)만 10dB 안팎 크게 했다. 계속 시끄럽지 않고 '터질 때 터지게' 하려는 것이다.
- 리미터 덕분에 어떤 소리도 0dBFS(찢어짐)에 닿지 않는다.

## 4. 지킬 것
- 소리 끄기를 존중하고 기본 음량은 중간으로 둔다. 설정에 **음악 / 효과음 음량을 따로** 둔다.
- 소리가 게임의 정답 정보를 흘리지 않게 한다(엔백 글자, 인원수 사람 수, 다른 색 찾기 위치).
- iOS 첫 터치 오디오 잠금 해제는 지금 코드(`_audioUnlock`)를 그대로 쓴다. 배경 탭 전환 시 음악을 멈춘다.
- 진동은 지금처럼 소리와 같이 간다.
