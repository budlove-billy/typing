## 우선순위 제안

1. **홈 레이아웃 흔들림(CLS 0.80 → 0.1 이하)** — 코어 웹 바이탈 '나쁨' 기준(0.25)의 3배. 원인: JS가 늦게 채우는 홈 칸(오늘의 추천 34→152px, 이번 주 챌린지 31→121px, 메달 컬렉션 31→114px)이 자리를 안 잡아 둬서 아래 전체가 밀린다. 칸 높이를 미리 잡아 두면 해결. 빠른 PC에선 0이라 지금까지 안 보였다.
2. **llms.txt 신설** — 사이트 소개·게임 34종·운세·데일리 퍼즐 주소를 AI가 읽는 안내서로.
3. **한국어 랜딩 11곳 FAQPage JSON-LD** — 화면 FAQ와 글자까지 같게. 참고: 구글은 2023년부터 일반 사이트에 FAQ 리치 결과를 거의 안 보여 준다. 효과는 AI 답변·빙·네이버 쪽.
4. **이름 통일 + sameAs** — 대표 표기 하나 정하기('플레이말로우(Mallow)'), 공식 SNS·스토어가 생기면 sameAs로 연결.
5. (사용자) 빙 웹마스터 도구 등록 여부 확인 — 홈에 빙 인증 메타가 없다. GSC 가져오기로 했다면 괜찮다. 서치어드바이저·GSC 주간 노출/클릭 확인.
6. (나중) 1차 데이터 페이지 — 예: '반응속도 평균은 몇 ms?' 같은 질문에 사이트 실측 분포로 답하는 페이지(GA4 결과가 쌓인 뒤).
