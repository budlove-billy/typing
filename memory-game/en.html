How to play

Every card starts face down. Turn two over: if the pictures match, the pair is cleared; if not, both flip back — and the whole game is about remembering what you saw and where it was.

Clear the board and the next one adds more pairs. Rather than flipping at random, it helps to sweep the board in a fixed order early on so the positions you have seen form a pattern you can recall.

This is the classic exercise for visual working memory — holding what you have just seen for a few seconds.
